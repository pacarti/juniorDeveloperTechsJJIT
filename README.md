<h1>juniorDeveloperTechsJJIT</h1>
The script takes the count of junior developer job offers in main IT specialisations and shows it in a bar chart form. The data is taken from <b>justjoin.it</b> website(one of the top Polish websites to find an IT job). <br><br>Additionally, for each technology, it prints out the exact count in terminal.
<br>
The results are sorted regarding the job offer count, descending.
<br><br>
<b>Update:</b> Because of updates done on the justjoin.it website, the chart is being generated now quite longer than before.
<h3>Specialisations shown:</h3>
<ul>
<li>Python</li>
<li>Java</li>
<li>PHP</li>
<li>JavaScript</li>
<li>Ruby</li>
<li>AI/ML</li>
<li>Testing</li>
<li>Mobile</li>
</ul>
<h2>How to use:</h2>
<code>./juniorDevJJIT</code><br><br>
The script requires the <b>matplotlib</b> module. Installation:<br>
<code>python -m pip install -U matplotlib</code><br><br>
Remember that when you run it for the first time, you have to give execution permission to the script:<br>
<code>chmod +x juniorDevJJIT</code>
